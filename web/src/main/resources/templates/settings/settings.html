JobWarden for Claude (MCP)
Lets Claude check whether your postings are still up, update their status, and find jobs for your saved searches.
MCP address
http://localhost:8080/mcp
In Claude Code, run:
claude mcp add --transport http jobwarden http://localhost:8080/mcp
Then ask Claude, e.g. “Check my open applications in JobWarden and close the ones whose posting is gone”.
