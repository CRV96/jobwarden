# The wiki's pages

Each `.md` file here, but this one, is a page of [JobWarden's wiki](https://github.com/CRV96/jobwarden/wiki), named
after the file: `Getting-started.md` is *Getting started*. `_Sidebar.md` and `_Footer.md` show beside and under every
page.

Change them here, in a pull request like the code. On every push to `main` that touches them, the
[Wiki workflow](../../.github/workflows/wiki.yml) copies them to the wiki, replacing what's there: an edit made on the
wiki itself doesn't last. A page links to another by its name, without `.md`: `[Updating](Updating#back-up-first)`.
